# Bayesian linear measurement inference in CHRONOS

## What is implemented

The module `backend/chronos_causal/bayesian.py` implements a mathematically exact conjugate analysis for the following restricted model:

[
y mid eta sim mathcal{N}(Xeta, C), qquad
eta sim mathcal{N}(m_0,S_0),
]

where (C) is a supplied, known, positive-definite measurement covariance and (S_0) is a proper, positive-definite coefficient-prior covariance.

The posterior is Gaussian:

[
S_n=(S_0^{-1}+X^T C^{-1}X)^{-1}, qquad
m_n=S_n(S_0^{-1}m_0+X^TC^{-1}y).
]

The marginal likelihood is evaluated analytically from
(ysimmathcal{N}(Xm_0,C+XS_0X^T)). For a finite set of candidate design matrices and explicitly supplied model priors, the module normalizes these marginal likelihoods into posterior model probabilities.

Posterior-predictive replicates are generated by drawing (eta^{(s)}) from the coefficient posterior and then (y_{mathrm{rep}}^{(s)}) from (mathcal{N}(Xeta^{(s)},C)). The endpoint reports predictive intervals and posterior-predictive tail areas for whitened residual discrepancies.

## API

- `POST /api/v5/causal/bayesian/posterior-predictive`
- `POST /api/v5/causal/bayesian/model-comparison`

The posterior-predictive request supplies `observed`, `design_matrix`, `covariance`, `prior_mean`, `prior_covariance`, `draws` and `seed`. Model comparison supplies a mapping of model names to design matrices, a proper coefficient prior for each model, and a positive prior probability for each model.

## What this does not establish

- BIC remains an information-criterion score. Normalized exp(-Delta-BIC/2) values are approximate relative support, not posterior model probabilities.
- A conditional parametric bootstrap at fixed predictions remains a frequentist conditional bootstrap. It is not retroactively converted into Bayesian posterior prediction.
- The new Bayesian posterior-predictive check is exact for the specified linear-Gaussian measurement submodel. It is not posterior sampling of the full CHRONOS sky, detector, spatial ePSF, wavelength-response, calibration, astrometry, selection and population model.
- The measurement covariance is treated as known. Calibration uncertainty must either be represented in a larger explicit probabilistic model or reported as an external systematic.
- Posterior model probabilities depend on the model set and all coefficient/model priors. Prior sensitivity and omitted-model checks are required before scientific interpretation.

The Bayesian routes are a research capability, not a claim of empirically validated SPHEREx model probabilities or a demonstrated Sky–Detector Twin performance advantage.
